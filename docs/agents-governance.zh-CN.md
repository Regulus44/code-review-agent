# AGENTS.md 治理说明

根目录 [AGENTS.md](../AGENTS.md) 是本项目的治理文件，负责约束长期目标、架构取舍、交付规则、安全边界和任务执行方式。当前能力与近期优先级见 [当前状态](status.zh-CN.md)，历史阶段资料统一放在 [archive](archive/)。

## 修改权限和触发条件

普通实现任务不得修改根 `AGENTS.md`。只有以下情况允许修改：

1. 用户明确要求调整开发原则或治理规则；
2. 已接受的架构决策、协议边界、交付规则或安全不变量发生变化，需要同步根规则；
3. 仓库运行方式发生稳定且长期的变化，需要更新强制命令或目录规则。

发现潜在过时内容时，先记录问题并请求确认，不把治理文件作为普通重构的一部分顺手改掉。

## 修改流程

每次修改必须：

1. 说明原因、影响范围、迁移要求和回滚方式；
2. 同步相关 ADR、契约文档、当前状态页和测试门禁；
3. 使用独立提交，提交信息以 `docs(governance):` 开头；
4. 在提交说明中列出受影响的目录和后续任务；
5. 通过 `git diff --check`，并运行受影响范围的验证命令。

## 不能依赖的“保护”方式

Git 默认不会阻止文件修改。`.gitignore`、本地 hook、`git update-index --assume-unchanged` 都不能提供可靠保护。若需要强制审查，应在远端仓库配置 branch protection 和 CODEOWNERS，让根 `AGENTS.md` 的修改必须经过项目负责人审核。
