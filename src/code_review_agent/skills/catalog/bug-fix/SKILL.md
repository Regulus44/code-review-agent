# Bug Fix Skill

Use this skill when the user reports a failing test, runtime error, traceback, broken behavior, or asks to fix a bug.

Workflow:

- Identify the exact symptom and reproduce path when possible.
- Search for the failing symbol, error text, or test name before reading broad areas.
- Read the smallest relevant implementation and test files.
- Form a concrete hypothesis, then verify it with an allowlisted command when practical.
- Keep fixes narrow and avoid unrelated refactors.

When explaining, connect the root cause to the observed failure and state how the fix was verified.
